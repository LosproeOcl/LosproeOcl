实践

  • 基于改进遗传算法的农作物种植策略优化 2024 年全国大学生数学建模竞赛论文；构建线性规划、改进遗传算法、动态规划、蒙特卡洛与模拟退火模型，比较滞销与降价情境下的种植方案。
  • EcoBot 环境治理机器人 国家级大学生创新创业训练计划项目；负责程序架构设计与核心模块实现，项目以优秀等级结项。
  • 机械臂手势识别控制系统 基于 OpenCV 实现手势识别与控制；软件著作权登记号 2025SR0318621。
  • 大数据处理链路 以 Docker Compose 编排 Kafka、Logstash、HDFS、Hive、HBase、Elasticsearch 与 Kibana，完成实时检索与离线分析。
  • 共享单车数据可视化 完成数据清洗、外部数据基准、静态与交互图表，以及 BI 看板。
  • 云计算应用部署 使用阿里云 SAE 部署 Python Web 应用。
